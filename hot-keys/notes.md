### PROMPTS ###

Stream mode is now my primary focus, turns out that's what I was looking for this whole time. The other modes are fun and random but without having a pre-determined track of notes that align with the beats for each song it just doesn't match up cleanly. Let's clean up a little bit and take it from there -

* Remove HotKeyS mode, that was a problematic mode from the get-go.  
* Straight Keys mode is still called Straight Keys but now functions exactly like Stream mode
* Shifty Keys mode is still called Shifty Keys and functions like Stream mode with Shift key strokes randomly intermixed
* Add a new mode: Spacey Keys. In between each key you must space the space bar. The space bar will be an extra keystroke placed on the interval beat before the next key. For example, on easy mode keystrokes are represented as whole notes. In this instance a keyspace would be required on the half note before the next whole note keystroke. 
* To summarize, there will be 3 modes, Straight Keys, Shifty Keys, and Spacey Keys. They all work like Stream mode currently works with their own modifiers
